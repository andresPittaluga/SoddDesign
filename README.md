# SoddDesign (repo de desarrollo)

Middleware de audio para Unity 6 de Sodd Studio. El paquete está en
[`Packages/com.sodd.sodddesign`](Packages/com.sodd.sodddesign/README.md); este repo es además el proyecto
Sandbox para probarlo (`Assets/Sandbox/Sandbox.unity`).

- Instalar en otro proyecto (git URL): `https://github.com/<usuario>/SoddDesign.git?path=/Packages/com.sodd.sodddesign#v0.1.0`
- Docs: [QUICKSTART](Packages/com.sodd.sodddesign/Documentation~/QUICKSTART.md) ·
  [Guía técnico de audio](Packages/com.sodd.sodddesign/Documentation~/GUIA_TECNICO_AUDIO.md) ·
  [Guía IA](Packages/com.sodd.sodddesign/Documentation~/AI_GUIDE.md) · [Estado del proyecto](PROGRESS.md)
- Tests en batchmode (aunque el Editor esté abierto): `bash Tools/ci.sh both`
