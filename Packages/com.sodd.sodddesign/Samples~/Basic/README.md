# Sample Basic

1. Importalo desde Package Manager > SoddDesign > Samples > Basic.
2. Si tu proyecto todavía no tiene `Assets/SoddDesign/sodd.settings.json` y `sodd.parameters.json`, copiá los de
   `Templates/` (sacales la extensión `.txt`).
3. Agregá `BasicDemo` a la cámara (o a cualquier objeto) y dale Play: botones Beep / Paso / Loop.
4. Abrí `Sodd > SoddDesign Studio`: los eventos aparecen en `samples/basic/`.
